Ridgeline: Merapi Ridge Run is an original flight game built for the make.fun best-flight-game-20261126-0057 bounty. Fly the Kestrel K-9 over a seeded Merapi valley — volcano cone, terraced rice fields, a river, a town and Adi Ridge Airfield — in a Canvas 2D voxel-terrain chase view. Three missions with different goals: Ring Run (8 gold rings in order), Ridge Rescue (low-level valley gates, bonus under 300 ft), and Runway Landing (gear down, under 120 kt, inside the touchdown zone). Throttle discipline matters: fuel burns faster at full power and hard manoeuvres cost extra; terrain strikes crash you and hard landings damage the airframe. Everything is hand-written and procedural from a fixed seed: the terrain, the town, the runway, the HUD with its lit instruments, and all sound synthesised with WebAudio. No libraries, no network requests at runtime.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Arrows / WASD fly, Shift throttle up, Ctrl throttle down, G gear, B airbrake, P pause, R restart, M mute, click toggles cockpit cam. Press 1, 2 or 3 on the title screen to pick a mission.
